# 第7讲：因子、cut与条件判断 - 知识点总结

## 1. 因子（factor）与水平（levels）

### 核心概念
- **因子**：R专门用来装「分类变量」的类型
- **水平**：这个分类变量一共有哪几个类别

### 主要函数
- `factor(x)`：将向量转换为因子
- `levels(f)`：查看因子的水平
- `nlevels(f)`：查看有几个水平
- `table(f)`：统计每个水平出现的次数

### 重要特性
- 因子底层存储的是整数，外面套着标签
- 长度是数据个数，不是水平个数
- 即使水平为0也会在统计中列出

### 易错点
- **不能直接赋值不在水平列表中的值**，会变成NA并警告
- 必须在创建因子时指定所有可能的水平
- 可以通过`levels`参数人为控制顺序

### 应用场景
- 控制绘图时的顺序（如成绩等级按"不及格、及格、良好、优秀"排列）
- 确保统计报表的行数稳定

## 2. cut()函数：连续变量分组

### 核心概念
- 将连续的数值切成有名字的几档
- 输出结果是因子类型

### 语法
```r
cut(x, breaks = , labels = )
```

### 参数说明
- `breaks`：切点，n个区间需要n+1个切点
- `labels`：每个区间的标签
- `right`：区间开闭方式，默认TRUE（左开右闭）

### 区间开闭
- 默认：左开右闭 `(a, b]`，如 `(1.5, 2.5]`
- `right = FALSE`：左闭右开 `[a, b)`，如 `[1.5, 2.5)`

### 易错点
- **breaks数量比labels多1**
- 边界值归属必须明确说明
- 分组后最好用`table()`检查分布

### 应用场景
- 年龄分组（如35岁以下、35-50岁、50岁以上）
- 成绩分级（如不及格、及格、良好、优秀）
- 风险等级划分

## 3. 条件判断函数对比

### if-else结构
```r
if (condition) {
  # 条件为真时执行
} else if (condition2) {
  # 条件2为真时执行
} else {
  # 都不满足时执行
}
```

### 特点
- **只能处理单个值**
- 用于控制程序走向
- else必须和if在同一行

### ifelse()函数
```r
ifelse(condition, yes, no)
```

### 特点
- **可以处理整个向量**
- 向量化函数
- 适合批量分类和填补缺失值

### 易错点
- ifelse嵌套超过两层就难以阅读
- 缺失值处理要特别注意

## 4. case_when()函数：多分支判断

### 语法
```r
case_when(
  condition1 ~ result1,
  condition2 ~ result2,
  ...
  TRUE ~ default_result
)
```

### 特点
- **可以处理整个向量**
- 语法清晰，易读
- 从上往下匹配，第一个命中就返回

### 易错点
- **顺序很重要**：从严格到宽松
- 默认分支在dplyr 1.0.x中必须用`TRUE~`
- 必须明确处理缺失值

### 应用场景
- 成绩多级分类
- 复杂条件判断
- 批量数据分类

## 5. switch()函数

### 语法
```r
switch(x,
  "value1" = "result1",
  "value2" = "result2",
  ...
)
```

### 特点
- 只能处理单个值
- 适合多选一的场景
- 常用于将编码转换为描述文字

## 6. 实用技巧

### 批量填补缺失值
```r
# 用0填补
ifelse(is.na(x), 0, x)

# 用均值填补
ifelse(is.na(x), mean(x, na.rm = TRUE), x)

# 用中位数填补
ifelse(is.na(x), median(x, na.rm = TRUE), x)
```

### 数据分析流程
1. 使用`cut()`进行分组
2. 使用`group_by()` + `summarise()`进行统计
3. 使用`ggplot2`进行可视化

### 代码风格
- 管道操作符`%>%`让代码更清晰
- 适当使用花括号提高可读性
- 注释说明分组边界和假设

## 7. 常见错误与解决方案

### 错误1：因子赋值新水平
```r
# 错误
f <- factor(c("A", "B"))
f[1] <- "C"  # 会变成NA

# 正确
f <- factor(c("A", "B"), levels = c("A", "B", "C"))
f[1] <- "C"
```

### 错误2：cut()的breaks参数
```r
# 错误：breaks和labels数量不匹配
cut(x, breaks = c(1, 2, 3), labels = c("低", "中"))

# 正确
cut(x, breaks = c(1, 2, 3), labels = c("低", "中", "高"))
```

### 错误3：case_when()的默认分支
```r
# 机房环境（dplyr 1.0.x）必须这样写
case_when(
  x > 0 ~ "正数",
  TRUE ~ "非正数"  # 不能用.default
)
```

### 错误4：条件顺序
```r
# 错误：宽松条件在前
case_when(
  x > 0 ~ "正数",
  x > 10 ~ "大于10",  # 永远执行不到
  TRUE ~ "其他"
)

# 正确：严格条件在前
case_when(
  x > 10 ~ "大于10",
  x > 0 ~ "正数",
  TRUE ~ "其他"
)
```

## 8. 实战建议

1. **明确边界**：在报告中清楚说明区间的开闭方式
2. **处理缺失**：明确处理缺失值，避免误分类
3. **检查分布**：使用`table()`或`count()`检查分类结果
4. **代码简洁**：优先使用`case_when()`而非嵌套`ifelse`
5. **注释完整**：说明分组逻辑和假设条件

## 9. 综合应用示例

### 成绩分析流程
```r
# 1. 读取数据
df <- read_excel("students.xlsx")

# 2. 单科分级
df <- df %>%
  mutate(数学等级 = cut(数学,
                        breaks = c(0, 60, 80, 90, 100),
                        labels = c("不及格", "及格", "良好", "优秀")))

# 3. 总分分级（处理缺失值）
df <- df %>%
  mutate(总分 = 数学 + 英语 + 语文) %>%
  mutate(总分等级 = case_when(
    is.na(总分) ~ "缺考",
    总分 >= 270 ~ "优秀",
    总分 >= 240 ~ "良好",
    总分 >= 210 ~ "中等",
    总分 >= 180 ~ "及格",
    TRUE ~ "不及格"
  ))

# 4. 统计分析
df %>%
  group_by(总分等级) %>%
  summarise(人数 = n(), 平均分 = round(mean(总分, na.rm = TRUE), 1))
```

### 风险评估流程
```r
# 1. 数据准备
cb <- read_excel("cb_packages.xlsx")

# 2. 风险分级
cb <- cb %>%
  mutate(风险等级 = case_when(
    申报价值 > 10000 & 通关时间 <= 3 ~ "高风险",
    申报价值 > 5000 ~ "中风险",
    TRUE ~ "低风险"
  ))

# 3. 按口岸分析
cb %>%
  group_by(入境口岸) %>%
  summarise(
    高风险数量 = sum(风险等级 == "高风险"),
    风险比例 = round(100 * sum(风险等级 == "高风险") / n(), 1)
  )
```

## 总结

本讲的核心是掌握如何将连续变量转换为分类变量，以及如何进行条件判断。关键是要理解不同函数的适用场景：
- `factor()`：处理分类变量
- `cut()`：连续变量分组
- `if-else`：单个值的条件判断
- `ifelse()`：向量的二分类
- `case_when()`：向量的多分类

在实际应用中，要特别注意边界条件的处理、缺失值的处理，以及代码的可读性。

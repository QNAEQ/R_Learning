# 第8讲 循环与向量化 - 知识点总结

## 一、核心概念

### 1. 循环 vs 向量化
- **向量化优先**：能用一行向量化代码解决的，坚决不用循环
- **循环何时必要**：
  - 当前步骤依赖前一步结果（如复利、还款）
  - 需要重复执行有副作用操作（如生成文件）
  - 循环次数不确定，需条件判断（如while）

### 2. 性能对比
- 向量化比循环快几十倍以上
- 数据量越大，差距越悬殊
- 向量化代码更简洁，可读性更好

## 二、for循环详解

### 1. 两种基本用法
```r
# 用法一：遍历元素
for (i in vector) {
  # i 直接是元素的值
}

# 用法二：遍历索引
for (i in 1:length(vector)) {
  # i 是位置，用 vector[i] 访问元素
}
```

### 2. 重要函数
- `seq_along(x)`：比 `1:length(x)` 更安全，空向量时返回空向量
- `cat()`：输出更简洁，适合循环中连续输出
- `print()`：带[1]和引号，适合调试

### 3. 经典错误
```r
# 错误：空向量会出错
for (i in 1:length(x)) ...  # 当x为空时，变成1:0

# 正确：空向量安全
for (i in seq_along(x)) ...  # 当x为空时，循环直接跳过
```

## 三、while循环

### 1. 核心特点
- 适合次数不确定的场景
- 必须确保条件最终会不成立
- 需要手动更新条件变量

### 2. 死循环预防
```r
# 错误：死循环
a <- 10
while (a > 0) {
  print(a)
  # 忘记 a <- a - 1
}

# 正确：避免死循环
a <- 10
while (a > 0) {
  print(a)
  a <- a - 1  # 关键：让条件向不成立发展
}
```

### 3. 应用场景
- 连加/连乘
- 贷款计算（还款月数不确定）
- 条件终止的迭代

## 四、循环控制

### 1. break
- 立即跳出整个循环
```r
for (i in 1:10) {
  if (i == 5) break  # 跳出，不执行后续
  print(i)
}
```

### 2. next
- 跳过本轮，继续下一轮
```r
for (i in 1:5) {
  if (i %% 2 == 0) next  # 跳过偶数
  print(i)
}
```

### 3. repeat
- 必须搭配break使用
- 至少执行一次
```r
repeat {
  # 至少执行一次
  if (condition) break
}
```

## 五、实际应用

### 1. 复利计算
```r
# 预分配是关键
output <- numeric(years + 1)
output[1] <- principal

for (i in 1:years) {
  output[i + 1] <- output[i] * (1 + rate)
}
```

### 2. 贷款计算
```r
# 先检查月供是否够付利息
if (payment <= loan * rate) {
  stop("月供不够付利息，永远还不完")
}

while (loan > 0) {
  loan <- loan * (1 + rate) - payment
  month <- month + 1
}
```

### 3. 蒙特卡洛模拟
```r
# 记录每次试验结果
results <- numeric(N)
for (i in 1:N) {
  # 模拟随机试验
  results[i] <- function()
}
# 画收敛曲线
cumulative_prob <- cumsum(results == target) / (1:N)
```

## 六、最佳实践

### 1. 编写高效代码
- 优先考虑向量化
- 必须用循环时，预分配向量
- 用 `seq_along()` 而不是 `1:length()`

### 2. 避免常见错误
- 检查循环终止条件
- 避免死循环（学会用Esc中止）
- 注意 `|` 和 `||` 的区别
- 理解 `%%` 是求余运算

### 3. 调试技巧
- 用 `print()` 调试，但最终输出用 `cat()`
- 小数据量测试逻辑
- 注意循环体内语句顺序

## 七、大数定律验证

通过蒙特卡洛模拟可以直观看到：
- 模拟次数越多，频率越接近概率
- 小概率事件需要更多次数才能稳定
- 收敛曲线呈现波动逐渐减小的特征

## 八、记忆要点

1. **向量化第一**：先问R有没有内置批量方法
2. **循环要有终**：确保条件会不成立
3. **预分配向量**：避免动态增长的性能灾难
4. **安全索引**：用`seq_along()`而不是`1:length()`
5. **控制流程**：break跳出、next跳过、repeat+break组合
